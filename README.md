One funny line, 100 characters, written by a small deterministic program for make.fun's "One Line, One Laugh" bounty: I bought a standing desk to be healthier, and now I just stand still eating chips at a taller table. The setup promises self-improvement; the punchline admits nothing changed except the height of the table.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt`.
